# General notes
This folder contains a collection of IDL routines used as tool in other codes. There are a whole variety of routines, from calculation of the magnetic field from a g file to reading TRANSP file

In principle, this folder does not contain any high lever end user routine as the rest, this is low level library to be used by the other codes.

Thus, this folder have no instructions not usage guide. If you wish to look around and try to find a piece of code you could use in your tool I wish you good luck and a fun afternoon in your quest!
